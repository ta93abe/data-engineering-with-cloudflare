# Snowflake Git Integration を Pulumi で管理する

## Context

`snowflake/*.sql` を Snowflake から直接参照・実行できるようにしたい。Snowflake の Git Integration 機能を使い、GitHub リポジトリを Snowflake 内のリポジトリステージとして登録する。リポジトリは public なので認証（Secret）は不要。

Pulumi Snowflake Provider v2.12.0 の制約:
- `snowflake.GitRepository` → ネイティブリソースとして利用可能
- `snowflake.ApiIntegration` → `git_https_api` プロバイダー**未対応**（ドキュメントに明記）
- → API Integration は `snowflake.UnsafeExecute` で生SQL実行が必要

## 変更対象ファイル

| ファイル | 変更内容 |
|---------|---------|
| `infrastructure/pulumi/snowflake.go` | Database `ADMIN`、API Integration（UnsafeExecute）、Git Repository 追加 |
| `infrastructure/pulumi/main.go` | 新しい Output（`snowflakeGitRepositoryName`）をエクスポート |

## 実装手順

### Step 1: ブランチ作成

```bash
git checkout main && git pull
git checkout -b feat/add-snowflake-git-integration
```

### Step 2: snowflake.go にリソース追加

既存の `createSnowflakeResources()` に以下を追加:

#### 2a. Database `ADMIN`

Git Repository の配置先。ツール・管理系リソース用のデータベース。

```go
adminDb, err := snowflake.NewDatabase(ctx, "admin", &snowflake.DatabaseArgs{
    Name: pulumi.String("ADMIN"),
})
```

#### 2b. API Integration（UnsafeExecute）

`git_https_api` は ApiIntegration リソース未対応のため UnsafeExecute で作成。

```go
gitApiIntegration, err := snowflake.NewUnsafeExecute(ctx, "gitApiIntegration", &snowflake.UnsafeExecuteArgs{
    Execute: pulumi.String("CREATE OR REPLACE API INTEGRATION git_api_integration API_PROVIDER = git_https_api API_ALLOWED_PREFIXES = ('https://github.com/ta93abe') ENABLED = TRUE"),
    Revert:  pulumi.String("DROP INTEGRATION IF EXISTS git_api_integration"),
})
```

#### 2c. Git Repository

```go
gitRepo, err := snowflake.NewGitRepository(ctx, "dataEngineering", &snowflake.GitRepositoryArgs{
    Database:       adminDb.Name,
    Schema:         pulumi.String("PUBLIC"),
    Name:           pulumi.String("DATA_ENGINEERING"),
    Origin:         pulumi.String("https://github.com/ta93abe/data-engineering-with-cloudflare.git"),
    ApiIntegration: pulumi.String("GIT_API_INTEGRATION"),
}, pulumi.DependsOn([]pulumi.Resource{gitApiIntegration, adminDb}))
```

#### 2d. SnowflakeOutputs に追加

```go
type SnowflakeOutputs struct {
    DatabaseName      pulumi.StringOutput
    SchemaName        pulumi.StringOutput
    WarehouseName     pulumi.StringOutput
    AdminDatabaseName pulumi.StringOutput  // 追加
    GitRepositoryName pulumi.StringOutput  // 追加
}
```

### Step 3: main.go に Output 追加

## 設計判断

- **Database `ADMIN`**: Git Repository は特定のDB.Schemaに属する必要がある。RAW（データ用）とは分離し、管理ツール系の専用DBを作成
- **Schema `PUBLIC`**: ADMIN DBのデフォルトスキーマで十分
- **UnsafeExecute**: ApiIntegration が `git_https_api` 未対応のため唯一の手段。Execute/Revert で冪等性を確保
- **認証不要**: リポジトリが public のため Secret なし、`GIT_CREDENTIALS` パラメータ省略
- **DependsOn**: Git Repository は API Integration と ADMIN DB に依存

## 使い方（デプロイ後）

```sql
-- リポジトリを最新に同期
ALTER GIT REPOSITORY ADMIN.PUBLIC.DATA_ENGINEERING FETCH;

-- ファイル一覧
LS @ADMIN.PUBLIC.DATA_ENGINEERING/branches/main/snowflake/;

-- SQL 実行
EXECUTE IMMEDIATE FROM @ADMIN.PUBLIC.REDACTED.sql;
```

## 検証方法

1. `go build ./...` でコンパイル確認
2. PR 作成 → CI の Pulumi Preview で +3 リソース（Database ADMIN, UnsafeExecute, GitRepository）の create が表示されること
3. マージ後、Snowsight で `LS @ADMIN.PUBLIC.DATA_ENGINEERING/branches/main/snowflake/` を実行し `bootstrap.sql` が見えること
