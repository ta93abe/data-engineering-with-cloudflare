# TA-307: Snowflake リソースを Pulumi で管理する

## Context

既存の Pulumi プロジェクト（Go）は Cloudflare リソース（D1, R2, KV）を管理している。Snowflake をデータウェアハウスとして活用するため、同じ Pulumi プロジェクトに Snowflake プロバイダーを追加し、基盤リソース（Database, Schema, Warehouse）を IaC で管理する。Phase 1 として基本リソースのみ対応。

## 変更対象ファイル

| ファイル | 変更内容 |
|---------|---------|
| `infrastructure/pulumi/go.mod` | `pulumi-snowflake/sdk/v2` 依存追加 |
| `infrastructure/pulumi/main.go` | Snowflake リソース定義追加（Database, Schema, Warehouse） |
| `.github/workflows/pulumi-preview.yml` | Snowflake 認証用環境変数追加 |
| `.github/workflows/pulumi-deploy.yml` | Snowflake 認証用環境変数追加 |

## 実装手順

### Step 1: ブランチ作成

```bash
git checkout main && git pull
git checkout -b feat/add-snowflake-provider
```

### Step 2: Snowflake SDK 依存追加

```bash
cd infrastructure/pulumi
go get github.com/pulumi/pulumi-snowflake/sdk/v2
go mod tidy
```

### Step 3: main.go に Snowflake リソース追加

既存のコードパターン（コメントブロック区切り、error-return-early、ctx.Export）に準拠して以下を追加:

- **import**: `"github.com/pulumi/pulumi-snowflake/sdk/v2/go/snowflake"` 追加
- **Database**: `RAW` - データ取り込み用
- **Schema**: `RAW.INGESTION` - sfDatabase.Name を参照して依存関係を明示
- **Warehouse**: `ANALYTICS_WH` - XSMALL, auto_suspend=60s, auto_resume=true
- **Outputs**: `snowflakeDatabaseName`, `snowflakeSchemaName`, `snowflakeWarehouseName`

認証方式: 環境変数による暗黙的プロバイダー構成（Cloudflare プロバイダーと同じパターン）

### Step 4: CI/CD ワークフロー更新

両ワークフローの `env:` ブロックに以下を追加:

```yaml
SNOWFLAKE_ORGANIZATION_NAME: ${{ secrets.SNOWFLAKE_ORGANIZATION_NAME }}
SNOWFLAKE_ACCOUNT_NAME: ${{ secrets.SNOWFLAKE_ACCOUNT_NAME }}
SNOWFLAKE_USER: ${{ secrets.SNOWFLAKE_USER }}
SNOWFLAKE_PRIVATE_KEY: ${{ secrets.SNOWFLAKE_PRIVATE_KEY }}
SNOWFLAKE_ROLE: SYSADMIN
```

### Step 5: ビルド確認

```bash
cd infrastructure/pulumi && go build ./...
```

## 設計判断

- **認証**: JWT (Private Key) - 環境変数で注入。CI/CD との親和性が高い
- **ロール**: `SYSADMIN` - DB/Schema/Warehouse 作成に必要十分な権限
- **Pulumi logical name**: Cloudflare の `"raw"` と Snowflake の `"raw"` は URN にリソースタイプが含まれるため衝突しない
- **`AutoResume`**: Snowflake Provider v2 では `pulumi.StringPtrInput` 型 → `pulumi.String("true")` を使用

## ユーザー手動作業（PR マージ後）

1. GitHub Secrets に `SNOWFLAKE_ORGANIZATION_NAME`, `SNOWFLAKE_ACCOUNT_NAME`, `SNOWFLAKE_USER`, `SNOWFLAKE_PRIVATE_KEY` を追加
2. Snowflake 側で RSA キーペア認証を設定
3. ローカルの `.env.local` にも Snowflake 環境変数を追加

## 検証方法

1. `go build ./...` でコンパイル確認
2. ローカルで `pulumi preview` 実行 → 3 リソース（Database, Schema, Warehouse）の create が表示されること
3. PR 作成後、CI の Pulumi Preview が正常に実行されること
